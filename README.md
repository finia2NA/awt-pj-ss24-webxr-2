# XR-DVBI

Project work for Advanced Web Technologies Project at TU-Berlin. The goal is to develop an XR TV-experience using DVBI.

This project is subdivided into the sub-projects of the DVBI library (`lib/`) and the xr app (`app/`). Find instructions on how to run the sub-projects in the respective READMEs.  
Additionally, mvp demos where we tried different technologies and approaches detached from the main app are in the `demos` directory.
