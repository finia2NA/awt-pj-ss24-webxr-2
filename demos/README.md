# Demos
This folder contains a number of demos or proof of concepts that we created throughout the lifetime of the project. Most of these can be ignored completely but we found them interesting to include anyway.

For example, we have a very minimal working example of *DASH.js* in uikit or our first tests using the `<Html>` tag in *three.js*.

If you are interested, feel free to look around but note that these are of no real importance to the final product.
